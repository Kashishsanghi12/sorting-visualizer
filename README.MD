# Sorting Visualizer

An interactive web-based Sorting Visualizer built using **HTML, CSS, and JavaScript** to demonstrate how different sorting algorithms work through step-by-step animations.

This project helps users understand sorting algorithms by visualizing how elements are compared, swapped, and arranged in ascending order.

## 🚀 Features

- Interactive visualization of sorting algorithms.
- Real-time sorting animations.
- Adjustable visualization speed.
- Random array generation.
- Easy-to-use interface.
- Multiple sorting algorithm implementations.

## 🧠 Sorting Algorithms Implemented

The project currently includes:

1. **Bubble Sort**
2. **Selection Sort**
3. **Insertion Sort**
4. **Merge Sort**
5. **Quick Sort**

## 🛠️ Technologies Used

- HTML5 – Structure of the application.
- CSS3 – Styling and layout.
- JavaScript – Sorting algorithms and interactive functionality.

## 💻 How to Run Locally

1. Clone this repository:

```bash
git clone https://github.com/Kashishsanghi12/shorting-visualizer.git
```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser.

4. Select a sorting algorithm and start visualizing!
